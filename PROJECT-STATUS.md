## 🚀 Quick Start

To view the website:
1. Open `index.html` in a web browser
2. Or use a local server (recommended):
   - VS Code: Install Live Server extension and click "Go Live"
   - Python: `python -m http.server 8000`
   - Node.js: `npx http-server -p 8000`
